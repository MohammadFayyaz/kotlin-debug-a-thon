Summary
Kotlin Debug-a-thon is an android app that was riddled with some pretty nasty Kotlin bugs. With those gone, it's a collection of widgets that now function as expected! This project involved debugging six different common errors in a Kotlin-based Android application.

Notes
This project was a great hands-on exercise for understanding common Kotlin exceptions and how to debug them in Android Studio. I learned how to identify issues like ClassCastExceptions, NullPointerExceptions, and infinite loops by reading error logs and inspecting the code.
